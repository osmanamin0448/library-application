# Library Application
A simple library project built as part of ** The Odin Project ** Full Stack JavaScript curriculum

## About The Project
This project is a simple library application that allows user to add and book delete

This project focuses on JavaScrip concept including :
- Functions
- Parameter and Argument
- Variables and scope
- `crypto.randomUUID()`;
- Classes
- dialog
- Inheritance

## Live Demo
<https://osmanamin0448.github.io/library-application/>

## How The Application Work
1. Click on the **New book** button in the top right corner
2. A pop up form appears
3. Enter book details i.e title, author and pages then choose read status
4. Click on **Add** to add book to library
5. Read status can be modified after adding book by clicking **Read Status**
6. Book can be deleted by clicking **Delete Book**
